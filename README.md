# P999 Game Website

Official marketing site for **P999** at [p999gaming.com.pk](https://p999gaming.com.pk).

## Stack

- Next.js App Router + TypeScript
- Tailwind CSS
- Poppins via `next/font`

## Develop

```bash
npm install
npm run dev
```

## Build

```bash
npm run build
npm start
```

## Key routes

- `/` — Homepage / APK pillar
- `/download-p999-game`
- `/deposit-money-in-p999`
- `/withdraw-money-from-p999`
- `/p999-for-pc`
- `/blog` — 4 SERP-backed guides
